# Assets

Place these files here before building:

- `icon.png` — 1024×1024 app icon
- `splash.png` — 1242×2436 splash screen (dark background #0a0a1a)
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `favicon.png` — 48×48 web favicon

## Quick placeholder setup

Run from project root:
```
npx expo customize
```

Or generate placeholders with any image tool. The splash background color is `#0a0a1a`.
